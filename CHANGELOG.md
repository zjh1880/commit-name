# Change log

English | [中文](./CHANGELOG.zh.md)

All notable changes to this project will be documented in this file.

## [1.1.0] - 2026-06-11

### Added

- Commit type, scope, summary, body, and footer overrides.
- `--breaking` footer support.
- `message` field in JSON output.
- `--max-body` line wrapping.
- Additional CLI argument tests.

## [1.0.0] - 2026-06-11

### Added

- `suggest` command for generating conventional commit messages.
- `sample` command for demo output.
- JSON output for CI integrations.
- Deterministic diff heuristics.
- Built-in Node.js tests.
- GitHub Actions CI workflow.
- Complete open-source project documentation.
